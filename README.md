# Smart Expense Tracker

A modern and responsive personal finance web application that helps users record income and expenses, monitor their balance, and visualize spending patterns through interactive charts.

## Features

- Add income and expense transactions
- Edit and delete existing records
- Real-time balance calculation
- Total income and expense summary
- Search transactions by category
- Category-wise spending visualization using a Doughnut Chart
- Monthly Income vs Expense Bar Chart
- Export transaction history as a CSV report
- Automatic data saving using Local Storage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it using a web browser.
4. Start adding your income and expense records.
